# Posting kit

Files: `motion-video.mp4` + `cover-motion.jpg`, `websites-video.mp4` + `cover-websites.jpg`

## Order
1. **Day 1: Motion video** (fun, shareable → builds followers fast)
2. **Day 2 or 3: Websites video** (shows your work → brings clients)
Post one per day, not both at once, so each gets its full push from the algorithm.

## Best times (UAE time)
- **TikTok:** 7–10 pm
- **Instagram Reels:** 12–2 pm or 8–10 pm
- **Facebook Reels:** 8–10 pm

---

## 1. Motion video

**Caption (TikTok / Reels):**
```
did you blink? 🟠 follow the ball till the end
```
Alternative:
```

```

**Pinned first comment (post it yourself right after):**
```
what should the ball do next? 👇 best idea gets animated
```
(This makes people comment → the algorithm pushes it. If someone gives a good idea, make it: free next video.)

## How to post (same steps on every app)
1. Upload the video.
2. **Add music in the app:** tap *Sounds / Music*, pick a trending track.
   - Set **music volume to 15–25%**, keep **original sound at 100%** (so the hops, boings and swishes stay audible).
   - Instagram/Facebook business accounts: use the "Sounds for business" library (other songs can get muted).
3. **Cover:** upload the matching `cover-*.jpg` (or pick that frame in the app).
4. Paste the caption + hashtags, post, then immediately post the pinned comment and pin it.
5. Reply to every comment in the first hour: it's the biggest signal to the algorithm.

## After 48 hours, check
- **Watch time / % watched to the end** → if under 40%, the start needs to be faster.
- **Shares + saves** → these matter more than likes.
- **Profile visits** → if high but few follows, fix your bio (say what you do in one line + WhatsApp link).
