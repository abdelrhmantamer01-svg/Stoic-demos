# React Bits

The real source of every component is in `components/<Category>/<Name>/` (JavaScript + CSS variant). Open the component's folder, copy the `.jsx` and `.css` into the project, and install the npm packages it imports (often `gsap`, `motion`, `ogl`, `three`, `@react-three/fiber`). Read its props at the top of the file before using it. Prefer the one effect that serves the page; don't stack several heavy WebGL backgrounds.
